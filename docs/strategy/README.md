# docs/strategy

Purpose: long-range Cozy development direction.

Belongs:

- product and engineering direction
- phase roadmap
- responsibility boundaries
- durable prioritization

Not allowed:

- detailed executable checklists
- implementation diary entries
- normative behavior contracts

Strategy documents define where Cozy is going. Current execution state belongs
in `docs/phase`.


Cozy owns the versioned consumer-neutral semantic publication producer boundary;
Textus CBD Support owns external integration, views, navigation and acceptance.
BoK remains the meaning authority and CNCF the runtime owner. The durable
[publication handoff](../design/cml-semantic-publication-handoff.md) distinguishes
external JSON from internal Scala APIs and retains qualified identity, explicit
gaps, provenance and semantic strength responsibilities. Follow
[Phase 54.7](../phase/phase-54.7.md) and its
[checklist](../phase/phase-54.7-checklist.md) for current execution and closure.
