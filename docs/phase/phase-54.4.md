## Closure criteria

- Use Case metadata preserves every declared supported semantic field and
  stable cross-reference.
- Representative fixtures prove `Use Case -> Workflow -> StateMachine ->
  Entity`, plus Structure and Classification navigation, without CML parsing or
  name-based reconstruction.
- The versioned consumer-neutral contract is accepted as a Cozy producer
  surface; Textus CBD Support Dashboard acceptance and SimpleModeling.org site
  editing, building, publication, deployment, upload, and push remain outside
  this Phase.
- The matching checklist, focused validation/review, and release closure are
  complete with reproducible evidence.

## Non-goals

- Reopening the stable identity/publication or prior metadata contracts.
- Dashboard rendering, external Textus CBD Support acceptance, or CML source
  parsing by consumers.
- SimpleModeling.org site mutation, publication, deployment, upload, or push.
- CNCF runtime lifecycle enforcement.
