for all four roles: video, infographic, article PDF and summary-slide PDF.
The directory name is historical: this root is the SimpleModeling.org data

is not a Maven artifact and does not inherit the CAR repository layout.

The owner-selected operational convention is:

```text
<warehouse-root>/media/<ja|en>/<category>/<article>/
  article.pdf
  slides.pdf
  infographic.svg
  video.mp4
  metadata.json  # optional, only when additional information is useful
```

article name, not a Document Project's physical `index.dox`). Category and article

alone need not do so. No reverse-lookup feature or new registry is required.

an optional metadata file in the same directory; do not require a redundant
manifest or hash/integrity ledger.
