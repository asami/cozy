### Canonical four-role warehouse contract and deployment (COZY-75-09)

The owner selects `/Users/asami/src/maven-repository` as the canonical warehouse
for all four roles: video, infographic, article PDF and summary-slide PDF.
The directory name is historical: this root is the SimpleModeling.org data
store, containing a CAR Maven repository as one independent area. Article media
is not a Maven artifact and does not inherit the CAR repository layout.

The owner-selected operational convention is:

```text
<warehouse-root>/media/<ja|en>/<category>/<article>/
  article.pdf
  slides.pdf
  infographic.svg
  video.mp4
  metadata.json  # optional, only when additional information is useful
```

`article` is the article source filename without its extension (the logical
article name, not a Document Project's physical `index.dox`). Category and article
names are shared across languages; category/article identifies one article and
the language directory selects its locale. Keep this convention unless there
is a concrete reason for an exception, documented in the owning declarations.
The full warehouse path must identify the originating article; the basename
alone need not do so. No reverse-lookup feature or new registry is required.
Additional details such as article URL, title or source association may live in
an optional metadata file in the same directory; do not require a redundant
manifest or hash/integrity ledger.

The intended public counterpart is
`https://simplemodeling.org/media/<ja|en>/<category>/<article>/<file>`.
This media language hierarchy is independent of the HTML site's `/en/` routing.
The previously recorded upload mapping covers `repository/` to `/repository/`;
it does not establish that `media/` is uploaded. Inspect and configure the
selected `media/` upload/URL mapping while preserving the CAR Maven area.
Local placement, upload and actual remote availability are separate outcomes.
The [path convention decision](../journal/2026/10/2026-10-06-phase-75-media-path-convention.md)
supersedes the earlier repository/video placement proposal for article media.
See the [operational convention note](../notes/article-media-warehouse-path-convention.md)
for examples and optional metadata guidance.
