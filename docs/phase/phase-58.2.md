## Authority boundary

- Phase 58 `content/core.yaml` remains the locale-independent recursive logic
  authority.
- Document Description owns complete localized prose and project-specific
  localized labels used to present exact referenced Core Steps and nodes.
- Summary Description owns deliberate concise selection, order, wording,
  coordinate-free semantic diagram selection, retained points, and explicit
  Document omissions.
- Generic Logical Pattern, node-role, Relation-type, and UI-chrome translations
  belong to Cozy locale resources rather than an Article-specific Scala map.
- Renderer code owns responsive layout, colors, typography, HTML, CSS, inline
  interaction, accessibility, print behavior, and physical presentation.
- Reference and generated HTML are review evidence, not semantic authorities.

## Reference contract

The SimpleModeling.org Article 9 files below are the initial UX and behavior
exemplars. Their exact identities must be recorded before implementation or
acceptance. Cozy output is compared by required information, semantic DOM,
interaction, accessibility, and representative responsive rendering, not by
requiring identical hand-authored bytes.

- `application-modeling.dox/review/reference/document-confirmation.html`
- `application-modeling.dox/review/reference/summary-confirmation.html`
- `application-modeling.dox/review/reference/README.md`

Before acceptance, the prototype must be semantically reconciled:

- containment, child-Step Flow, and local Structure use distinct visual and
  DOM contracts;
- every visible edge resolves to an exact typed Core Relation or Flow
  transition;
- inverse display is explicit and does not change source semantics;
- Summary status reports unresolved/invalid references rather than implying
  full Core coverage; and
- complete hashes and diagnostic metadata remain secondary to review content.

## Closure criteria

- A reviewer can select any Core Step and distinguish its containment position,
  direct-child Flow, local Structure, and corresponding document prose.
- A reviewer can select any Summary Unit and inspect its slide-level semantic
  explanation, exact Core sources, retained points, and explicit Document
  omissions.
- Every primary project-specific label comes from admitted localized content;
  every generic label comes from Cozy locale resources.
- Renderer code contains no Article 9-specific Step, node, heading, or prose
  map and performs no semantic inference.
- Missing labels, unresolved diagram items/edges, invalid inverse declarations,
  unresolved Document omissions, stale identities, and unknown fields reject
  deterministically before output publication.
- Existing v1 load, validation, identity, rejection, and rendering obligations
  remain executable and passing.
- Repeated rendering of identical admitted bytes yields identical HTML bytes
  and output identity.
- Generated HTML is self-contained, safely escaped, keyboard-operable,
  responsive at representative desktop and mobile widths, and requires no
  external Web resource.
- Focused validation, independent full Phase review, full Cozy validation, and
  a distinct Phase release commit close the Phase.

## Exclusions

- Reopening or rewriting completed Phase 58 or Phase 58.1 history.
- Permissive v1 field admission or silent v1-to-v2 inference.
- Migration of every Document Project, scaffold, profile, Work Product, or
  production export route.
- SmartDox generation or SimpleModeling.org site integration.
- Article PDF, summary-slide PDF, PPTX, infographic, video, publication,
  registration, deployment, upload, push, or external-service mutation.
- Automatic semantic inference or automatic acceptance of AI-authored content.
