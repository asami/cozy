## Contract boundary

- `content/core.yaml` is the only semantic authoring authority in this slice.
- Core has no locale suffix and no root locale field.
- One recursive root Step owns its local Structure, child Steps, and child
  Flow.
- Child Flow is scoped to one parent and normally relates only its direct
  children.
- Step-local Structure reuses the established typed Logical Pattern, semantic
  node, and typed Relation concepts where compatible.
- Format input binds stable Core identities and owns locale-sensitive,
  reader-facing wording.
- Both HTML products are deterministic self-contained projections of the same
  validated Core and format binding; neither becomes authority.

## Required outputs

1. A logic-tree overview HTML that visually shows nested Step containment,
   Flow among Steps, and local Structure inside each Step on one document.
2. A 16:9 Step-slide HTML with one page per Step, ancestor context, local
   Structure, child Flow, direct children, and deterministic depth-first
   navigation.

Diagnostic identities and validation evidence may remain machine-readable or
secondary. Tables are not the primary reader-facing representation of either
output.

## Closure criteria

- Paired design, Markdown specification, and Executable Specification define
  the recursive Core and both renderers consistently.
- The validator rejects containment cycles, duplicate ownership, unresolved
  endpoints, out-of-scope child Flow, unknown or lossy input, and locale in
  the Core authority.
- The real Article 9 driver uses `content/core.yaml` and one explicit Japanese
  format binding.
- Both HTML products contain every declared Step, child Flow, and local
  Structure and have deterministic byte identities.
- Focused validation, one independent Phase review, full Cozy validation, and
  a distinct Phase release commit close the Phase.
