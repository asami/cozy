## Native command sequence

The runner supplies a reviewed Cozy executable as `COZY`, an isolated project copy as `PROJECT`, declaration as `DECLARATION`, package as `PACKAGE`, external work root as `WORK`, and every applicable synchronization root as `SYNC`. Run through the registered Cozy command runner. These are command templates, not executed evidence:

```sh
"$COZY" document-project package place "$PROJECT" --save "$PACKAGE" --declaration "$DECLARATION" --work-root "$WORK" --sync-root "$SYNC"
"$COZY" document-project package refresh "$PACKAGE" --product article-pdf --locale ja --product infographic --locale ja --product summary-slides --locale ja --product audio --locale ja --product video --locale ja --product article-pdf --locale en --product infographic --locale en --product summary-slides --locale en --product audio --locale en --product video --locale en --work-root "$WORK" --sync-root "$SYNC"
"$COZY" document-project package refresh "$PACKAGE" --product article-review --locale ja --product article-review --locale en --work-root "$WORK" --sync-root "$SYNC"
"$COZY" document-project build "$PACKAGE/source/PROJECT_PATH" --target document-structure-html --work-root "$WORK"
"$COZY" document-project build "$PACKAGE/source/PROJECT_PATH" --target document-reader-html --work-root "$WORK"
```

Replace `PROJECT_PATH` with the declaration's actual project path. The build command accepts `--locale` only for media targets; use the package article-review selections for localized HTML. preserve command, exit status, logs and external run receipt.
