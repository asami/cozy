# Phase 47.1 Producer-Handoff Decision

Decision ID: `P47.1-CROSS-REPOSITORY-BOUNDARY-001`

Date: 2026-09-08

Status: recorded

## Decision

The direct user-selected decision is `producer-handoff`.

Cozy owns the producer side of Phase 47.1: CML semantic action metadata,
static validation, deterministic generated producer-contract evidence, and the
handoff. `goldenport-cncf` Phase 64.1 alone owns UnitOfWork execution, optional
2PC capability and admission behavior, compensation execution, durable
`RecoveryRequired` behavior, and runtime proof of those outcomes.

This decision keeps Phase 47.1 focused on a factual Cozy inventory and a clear
producer/consumer boundary. Phase 47.2 and unrelated phase or strategy
projections remain out of scope.

## Rationale

The current Cozy inventory in
[`cml-action-transaction-compensation-inventory.md`](../../../notes/cml-action-transaction-compensation-inventory.md)
shows that CML Actions currently accept only `OPERATION`, that normalized
logical Actions and occurrences contain identity/operation/input/source and
placement/provenance data, and that CSM-04/CSM-07 explicitly defer execution,
transaction, compensation, and recovery policy. Existing generated operation
projections still expose `UnitOfWorkOp` placeholders rather than a completed CML
Action runtime path.

The closed Phase 47 precedent records the same kind of producer-side handoff:
the [Phase 47 checklist](../../../phase/phase-47-checklist.md) closes CSM-10 as a
Cozy producer handoff while keeping CNCF runtime acceptance outside Cozy. The
[Phase 47.1 contract](../../../phase/phase-47.1.md) applies that ownership boundary
to the future transaction/compensation producer contract.

## Non-claims

This record does not claim that Cozy currently implements the v1 metadata,
transaction syntax, compensation body, Saga DSL, runtime execution, rollback,
optional 2PC admission, compensation success/failure, or durable
`RecoveryRequired` behavior. It does not record an external repository revision,
and it does not imply that CNCF runtime work has started or completed. The exact
v1 CML syntax and concrete metadata/ABI field representation remain later ACTX
work.
