## Inspected cause and parent-frozen policy

Pre-edit inspection found that `CmlSemanticFoundation.SourceAttribution`
required `sha256`, `_source_diagnostics` validated its format, the semantic
writer emitted it at element, Term, reference and Derived-input positions, and
the semantic reader required it through an exact source-object field set.
`CmlStructureMetadataCodec._record` compared supplied embedded JSON directly
with canonical core JSON. Thus ignored historical source extras could still
contradict Structure binding even when the remaining typed facts agreed.

P71001-G01 removal is original Phase 71 global work under
[file update management](../../../spec/file-update-management.md) and the
[digest inventory](../../../design/phase-71-digest-purpose-inventory.md).
Implementation Manifest `8a89a9dc-0383-4a66-94b9-39732ada985e@2` freezes
`SourceAttribution(authorityId, path, line)` and ordinary required-field
projection. Unknown source extras of any JSON type are ignored without named
hash inspection in production. Explicit null line is absent; missing known
fields, invalid canonical paths, nonpositive lines, authority mismatch and
genuine semantic failures remain invalid. Opaque extension data stays exact.
No hash, snapshot, currentness, replacement receipt or content identity is
provided by attribution.

The parent explicitly retains `cozy.cml.semantic-metadata.v1` and
`cozy.cml.structure.v1` as the Phase 71 non-integrity retirement exception to
historical all-core-changes-new-version wording. There is no legacy decoder,
upgrade, alternate version or fake value. Future material core semantics still
require independently designed versioning.

Structure uses one empty-extension semantic envelope built from its admitted
Catalog for each embedded record. At each authored candidate index it replaces
only that element with the supplied JSON, invokes the same ordinary semantic
reader over the full Catalog context, and compares the resulting full typed
ElementRecord with the original at that index. It returns the first matching
original record. No match yields safe InvalidCoreBinding at the existing logical
coordinate. Catalog references, identities, authority and duplicate validation,
and Structure category, coverage and anonymous multiplicity remain unchanged.
