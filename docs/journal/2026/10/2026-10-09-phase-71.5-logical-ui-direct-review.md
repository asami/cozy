## Frozen boundary and implementation

The [S23 Implementation Manifest](../../../../.codex-workflow/phases/PHASE-71.5/p715-02-s23-implementation-manifest.json)
selects the LogicalUI part of original
[R715-06](../../../design/phase-71.5-removal-work-list.md) under the
[artifact-protection removal decision](../../../design/artifact-protection-removal.md).

The candidate retains normalized input and canonical content/JSON. Acceptance
retains the actual candidate and explicit decision ID. Screen and semantic
projection inputs no longer carry management identities, and their canonical
content consumes their typed normalized input. The original candidate schema
and version remain; the codec retains closed-field, duplicate, required, type,
JSON, and domain admission.

Review retains deterministic escaped HTML, substantive semantic/navigation/
constraint/state tables, informational diagnostics, and UTF-8 byte encoding.
Its overview shows schema, renderer profile, and explicit acceptance decision
ID. Receipts, digest rows, cross-stage currentness/revalidation, and custom
review-copy certificates are deleted. Required-value checks report
`LUI43_REVIEW_INPUT_INVALID` at the actual missing-input path. The selected
output path is admitted once with existing parent/direct-child/suffix/symlink/
traversal/regular-target checks. HTML writes directly with create/write/truncate;
ordinary I/O/security/runtime failures report failure and may leave partial
generated output. Regeneration is recovery.

compatibility fixture is added. Existing normalized semantic and HTML ordering
