# Phase71.8 video/audio quality profile planning

Date: 2026-10-11
Status: planned; implementation not started

The user requested, in a side conversation while Phase71.7 continues:

> 今は71.7だから71.8として追加しよう。
> 動画の品質をprofileで指定可能にして、映像と音声を合わせるようにしたい。
> 現在の映像のデフォルトはstandard?

Read-only code inspection established that `VideoRenderer.resolveEncoding`
defaults to `VideoEncodingPolicy.Lightweight`,18fps,1280×720 and CRF32.
`standard` is an explicit alternative,30fps,1280×720 and CRF23; `quality` is
30fps,1920×1080 and CRF18. Audio is currently fixed AAC320k,48kHz stereo,
with18000Hz cutoff in the native/mixed frame encoder, Docker Remotion mux and
final assembly.

Added the [Phase71.8 plan](../../../phase/phase-71.8.md), its
[unchecked ledger](../../../phase/phase-71.8-checklist.md), a
[non-normative candidate note](../../../notes/video-quality-profiles.md) and
the Strategy registration. Candidate AAC bitrates128k/192k/320k require actual
listening before acceptance; no new default or public schema is implemented.

This addition creates future planning documents only. It does not extend the
active71.7 Goal, move its aggregate validation, rewrite its accepted results,
alter source/runtime configuration, start SBT or create a commit. Keep these
71.8 planning paths separate from71.7's exact acceptance/release manifests.

## Same-day refinement: shifted ladder and practice profile

The user then directed:

> 現在のlightweightをstandardという名前にして、全体を右にシフト。新standardよりも品質が悪いが高速に生成できる習作用のプロファイルを作りたい。

Updated the future71.8 plan, unchecked ledger, candidate note and Strategy.
The intended ladder is new lightweight for practice, new standard using current
lightweight picture settings, new quality using current standard, and an upper
tier using current quality. The proposed upper name is `high-quality`.
The new default label is standard while retaining18fps/720p/CRF32 picture
settings. Explicit old selections require a documented migration.

Initial practice candidates are12fps,854×480,CRF36,superfast software encoding
and AAC96k. Shifted standard/quality/upper audio candidates are128k/192k/320k.
These are planning candidates, not executed or accepted settings. Measure
actual render/encode/total speed against new standard on comparable inputs and
retain useful storyboard/layout review and narration. No bitrate/CRF-derived
speed guarantee is claimed, and no71.7 source, runtime or Goal was changed.

The user explicitly confirmed: 「デフォルトは新standardね。」
Recorded new standard as the71.8 default; the new practice lightweight profile
is explicitly selected. Default picture settings remain18fps,720p,CRF32.
