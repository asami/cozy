## Implemented contract

Direct Inputs now contain the four selected versions and sourceIdentity.
Artifact is path-only. SourceInput holds the normalized actual selected Path
and canonical logical identity. The source snapshot, byte capture, hash fields,
digest helpers, content-equality checks, source-copy materialization, eager
metadata deletion, and hash-only diagnostic objects are removed.

V1 and V2 schema names and metadata location are unchanged. The JSON codecs
load strict required known fields and types through ordinary object loading,
ignore arbitrary unknown extras at every object level, and emit only the known
nonhash projection. Nonempty exact versions, canonical safe relative paths,
nonempty sorted unique artifact/source lists, and the v2 source/output union
remain required. There is no hash adapter, replacement token, content
certificate, ownership certificate, or source selection by enumeration/order.

The source is independently opened/closed to surface actual access failures.
The modeler and model metadata consume the actual selected normalized source
path. Generated Scala enumeration retains the existing target and delegated
root exclusions, opens/closes selected regular files, and compares actual and
declared path inventories. Readable source/output content changes alone are
admitted. Required access/path, malformed known-field, missing-evidence,
unsafe/ambiguous source, and exact-version failures remain typed and actionable.

Aggregation retains explicit manifest/output-root pair ownership, validates
all delegated v1 stage contracts, requires unique sorted canonical sources
and one exact version tuple, checks installed output excluding delegate work,
and emits the sorted path union. Shared paths deduplicate even when readable
contents differ. Both metadata writers complete stage validation before final
metadata replacement, validate temporary JSON, atomically move it to the final
path, and clean temporary files. Prior successful metadata and preflight output
survive modeled stage/preflight failures; no new backend source installer
transaction is claimed.

The metadata-validator CLI needs the actual model, --save, --cncf-version,
--cozy-generator-version, --generation-source-identity, and optional current
model version. It uses the compiled backend/default model versions and prints
the success path without an evidence token. It no longer reads source/descriptor
hash options. Packaged-only utilities are requireValidPackagedMetadata and
aggregate validatePackagedMetadata; they check known facts and path declarations
without local project source access.
