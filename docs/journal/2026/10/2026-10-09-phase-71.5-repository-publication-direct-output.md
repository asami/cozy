## Implementation facts

[RepositoryArtifactPublisher](../../../../src/main/scala/cozy/archive/RepositoryArtifactPublisher.scala)
now reads/merges the actual index, retains source/domain preflight, resolves the
selected archive and CAR sidecars, constructs the catalog/index/Maven metadata,
and copies/writes/deletes final output in the frozen order. Current SHA sidecar
emission reads the actual copied target. After actual detailed catalog/archive
validation, the index is written directly last. Index locks, fault seams,
candidate overlays, staging, snapshots, restoration and atomic replacement are
removed. Generated build-archive cleanup preserves primary errors with suppressed
cleanup errors, or reports cleanup failure after otherwise successful output.

[ComponentRepositoryIndex](../../../../src/main/scala/cozy/archive/ComponentRepositoryIndex.scala)
exposes two-argument `validateCatalogs(index, indexPath)` and direct
`write(path, index)`. Actual catalog loading, coordinates, namespace/id, warehouse
parent, lifecycle/selectors, SAR canonical contained paths and selected regular
archive checks remain. Checksum/integrityKey comparisons and SHA sidecar byte
admission are removed. The two existing write callers use the direct API.

[CozyCarPublisher](../../../../src/main/scala/cozy/archive/CozyCarPublisher.scala)
admits the real prebuilt archive before calling publication directly. Required
real generation provenance is validated once and passed to existing runtime
admission; snapshot inputs and argument substitution are removed. Generation,
compatibility, canonical admission and generated temporary CAR behavior remain.

[LegacyComponentRepositoryMigration](../../../../src/main/scala/cozy/archive/LegacyComponentRepositoryMigration.scala)
checks strict schema/duplicates and complete/used explicit mapping, then directly
copies canonical archives, writes current real digest/catalog output and copies
optional metadata sidecars. Source containment/non-symlink regular-file checks
and ordinary non-regular/symlink destination collision diagnostics remain.
Regular destinations are overwritten without byte comparisons. Actual catalog
validation precedes the direct index write last. Legacy inputs and unrelated SAR
entries remain. Prepared/Staged/Snapshot models and transactional helpers are
removed. Ordinary failures may leave partial final output; no visibility,
retry, idempotence, prior-output preservation or lost-update guarantee is made.

- `remove preparation and snapshot artifacts without mutating publication output when candidate construction fails`
- `clean every earlier rollback snapshot when a later snapshot backup fails before forward mutation`
- `leave final bytes and transaction directories unchanged when candidate validation fails`

`_existing_publication_bytes` / `_transaction_debris` helpers and `Instant`
