allowing a missing later entry to destroy a previous successful output.

consumer. Reduced ordinary JSON models ignore unknown extras, including old
hash values of any JSON type. Selection uses `apiClass` among exact declared
coordinates, keeping required/optional semantics and real ambiguity. Exact

membership remain admission contracts. Shared selected JARs are consolidated
after selection by declared coordinate, normalized archive path and artifact
path in first selected order; this is output deduplication with no ABI or
content-compatibility guarantee.

Replacement extracts every selected JAR into a task-created sibling stage.
Only after successful staging is a prior directory moved to an owned sibling
backup and the complete stage installed. Installation failure attempts
restoration and preserves the original install exception. Restoration failure
remains suppressed diagnostic evidence with the unrestored recovery backup
retained; cleanup failure after successful restoration is separately reported
as empty-backup cleanup evidence. After completed installation, deletion failure
of the prior backup emits an actionable warning naming its path and original
cause, retains the remaining backup, and returns successful final output paths.
Non-directory and symbolic-link outputs are rejected without deleting their
targets. An empty optional result installs an empty directory. Failed staging
is cleaned without clearing earlier output. No crash or concurrency guarantee
is added.
