# Model editing source boundary

The [source contract](../spec/cml-model-edit-production.md) is additive to the
accepted semantic publication v1 families. It supplies source production, typed
admission, and candidate rendering without changing those families or CBD's
editing/promotion services.

The existing Capability source acquisition owns physical file selection, UTF-8
and ordinary Kaleidox parsing. The model-edit producer consumes the same parsed
LogicalSection representation, using the existing original-root traversal.
It then admits one reserved leaf of explicit records. This avoids deriving
identity or causation from ordinary CML headings, display labels or source order.

The public Scala 2 model is an immutable object-owned ADT. Public JSON readers
admit closed shapes, supported versions, complete explicit references, local
endpoint revisions, kind-compatible trace relationships and independently
declared evidence coverage. Reading a serialized producer record is not runtime
authentication. Actual production reports compile-generated BuildInfo version,
Git revision and modified state; source provenance remains explicitly selected.

Candidate operations select exact original references. Refinements preserve
stable owner/identity and use explicit successor revisions. The resulting graph
is admitted before rendering. Endpoint changes require explicit corresponding
relationship edits. Source ownership restricts edits independently of whether
another owner's data happens to be resident. External references never trigger
resolution, ticket actions or source writes.

The renderer replaces the source-owned MODEL-EDIT block and preserves unrelated
source text. It uses the actual parsed root locations, including mixed `#` and
`*` outline headings, rather than scanning one physical heading spelling.
Missing locations or a non-exact MODEL-EDIT header are an explicit unsupported
rendering result. It returns a proposed string, not a canonical writer. Parsing that
string through the same acquisition/production route supplies the successor
projection. New record creation and arbitrary legacy syntax rewriting are
explicit initial limitations. Caller-owned CBD candidate approval and canonical
promotion remain outside Cozy.

The public JVM CLI main provides an executable interoperability surface without
requiring a Scala 3 consumer to link Scala 2.12 case classes. It emits the same
versioned JSON read by the public reader. A normal development runtime classpath
export is a usable delivery; shared publication and global installation are not
required by this boundary.
