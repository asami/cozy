# Finding Disposition producer boundary

The ordinary CML AST retains a `FINDING-DISPOSITION` document division. Explicit
component and declaration headings bind its native properties to actual component,
service and operation identities from that same model. The producer validates
source shape and exact binding and retains CNCF's eight portable fields.

The Scala 2.12 producer does not load the Scala 3 normalized decision classes.
Its generated Scala 3 source calls the already accepted CNCF public decoder;
there is no private cross-version runtime adapter or duplicated disposition
interpreter. The CML-source inspection reports its own diagnostics and coverage,
and never labels source declarations as actual CAR lint observations.

The existing Modeler routes compose the additional source Realm after their
current ScalaGenerator output, preserving that generator's constructor ABI.
The absence of the feature preserves
ordinary output. Pure-library output explicitly rejects this runtime feature.
No annotation insertion, source rewrite, generated-source readback, Human-policy
engine, runtime selection or consumer mutation belongs to this implementation.

The CBD requester owns result adoption, artifact activation and integration.
The current native GoalPhase owns producer validation, independent review and
local commits. Necessary ordinary local publication uses LocalPublicationService.
The earlier DelegateTask was force-closed as NotAccepted at the user's explicit
request on 2026-11-05; its failures and four consumed repairs remain historical
evidence, not a successful producer delivery. Those actual outcomes remain
separate from implementation and are not claimed by these design documents.
